Create GraphQL based WEB API for **Catalog Service**.

**Functional Requirements:**

1. The following actions should be supported:
    1. A list of categories
    2. A list of products (filtration by category id and pagination) with categories as subgraphs
    3. Add category
    4. Add product
    5. Update category
    6. Update product
    7. Delete product
    8. Delete category (with the related product)
        
2.  All actions should be accessible only with permissions/roles used in Catalog service from previous modules.
    

**Non-functional Requirements (NFR):**

1. Testability
2. Performance (pay attention to the DB interaction aspect – number of requests, amount of data returned, 1+N problem)
