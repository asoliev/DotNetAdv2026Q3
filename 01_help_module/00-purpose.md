Before the program start  
--------------------------

1.  Check the access to the education plan at **learn.epam.com** (My Learning Tab). 
2.  Study Learn Manual for [mentee](https://kb.epam.com/display/EPMLND/Tools?preview=%2F1180670748%2F1216807783%2FLearn+instruction_mentee.pdf) and [mentor.](https://kb.epam.com/display/EPMLND/Tools?preview=%2F1180670748%2F1216807775%2FLearn+instruction_mentors.pdf) 
3.  Join the MS Teams channel. 
    

Rules 
------

1.  Please read the “Roles and Responsibilities” in the attached.
2.  Both mentors and mentees have to notify the program curator via email about any changes that may affect mentoring deadlines. It is necessary to add the RM and mentor/mentee to CC. 
3.  Vacation, sickness, and business trips are the only valid reason for the deadline shift.   
4.  If a mentor or a mentee is not able to continue participating in mentoring due to any reasons, it is obligatory to inform a local coordinator, a RM,- and a mentor/a mentee immediately. Please, don't leave mentoring without any notice. 
    

During the program 
-------------------

**General statements:**  

1.  The program consists of a number of modules. Mentees should pass modules one by one using the Learn portal.  
2.  Mentees are expected to study program materials (video recordings, presentations, e-learning courses, etc.) and fulfill the home task. 
3.  Attend a Q&A Session with mentor/expert.
    

**1-to-1 mentoring:**  

1.  Mentor is supposed to check and evaluate assignments at each module. 
2.  Pass the final interview/ complete the final task if there is any. 

**Group mentoring:**  

1.  Set up an introductory meeting with your group.  
2.  Mentor is supposed to check and evaluate assignments at each module. 
3.  Agree on Group Q&A Sessions schedule. 
    

**Peer mentoring**:  

1.  Set up an introductory meeting with your peers. 
2.  Follow evaluation criteria while checking the home task. 
3.  Agree on Expert’s Q&A Sessions schedule. 
4.  Use MS Teams chats to ask questions, discuss program materials and assignments. 
    

**NB! Please, don't forget to update the statuses of each part of the module.**  

End of the program 
-------------------

1.  Completion criteria: 

*     Mentees should pass all mandatory modules. 
*    The program is regarded to be completed if all of the modules are done with an average mark of 60<. 

2. Mentors and mentees get badges at [https://heroes.epam.com/](https://heroes.epam.com/).  
If the average mark is **90 and higher**, a mentee gets "Best Mentee” badge.
